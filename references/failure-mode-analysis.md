# Failure Mode Analysis

## Canonical path

```text
TRIGGER
↓
WEAK POINT
↓
FAILURE
↓
IMMEDIATE IMPACT
↓
SECONDARY IMPACT
↓
CASCADING FAILURE
↓
MITIGATION
↓
EARLY WARNING
```

A useful failure mode explains the mechanism, not just the label.

Prefer concrete chains over generic categories such as "execution risk".

# Causal Identification

Inspect:

- exposure / intervention
- outcome
- temporal order
- comparison / counterfactual
- confounding
- selection
- measurement
- mechanism
- alternative explanations
- external validity

Classify only as strongly as the evidence supports:

- `CAUSAL EVIDENCE SUPPORTED`
- `CAUSAL EVIDENCE LIMITED`
- `ASSOCIATION ONLY`
- `CAUSALITY UNRESOLVED`

# Evidence Audit

For each material evidence item inspect:

- exact claim supported
- source
- original / primary source
- lineage
- date / freshness
- relevance
- scope
- methodology
- verification status
- limitations
- counterevidence
- conflict
- dependence

## Dependence

Sources can be dependent when they share a dataset, upstream report, official release, event, model, or copied claim.

## Status labels

- `VERIFIED`
- `PARTIALLY VERIFIED`
- `UNVERIFIED`
- `CONTESTED`
- `STALE`

Never inflate verification status.

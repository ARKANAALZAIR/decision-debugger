# Second-Order Effects

Second-order analysis asks what happens after the immediate effect of an option, not merely whether the first-order outcome is positive or negative.

Inspect where relevant:
- behavioral responses
- incentive changes
- stakeholder reactions
- downstream operational effects
- resource reallocation
- feedback loops
- externalities
- new dependencies created by the decision

Use conditional chains:

```text
ACTION
  → FIRST-ORDER EFFECT
  → RESPONSE / ADAPTATION
  → SECOND-ORDER EFFECT
  → POSSIBLE FEEDBACK LOOP
```

Do not invent second-order effects merely to make the analysis look comprehensive. Include only effects that are plausible enough and material enough to affect the decision.

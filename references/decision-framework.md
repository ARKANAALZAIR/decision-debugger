# Decision Framework

## Framing minimum

```text
Decision
Objective(s)
Constraints
Options
Owner
Decision rights
Stakeholders
Time horizon
Reversibility
Stakes
```

## Decision chain

```text
OBJECTIVE → CONSTRAINTS → OPTIONS → EVIDENCE → ASSUMPTIONS
→ REASONING → DEPENDENCIES → FAILURE MODES → SCENARIOS
→ ALTERNATIVES → FEASIBILITY → STAKEHOLDERS / AGENCY
→ REVERSIBILITY → BOUNDARIES → REASSESSMENT
```

## State precedence

```text
INSUFFICIENT EVIDENCE
→ CONTESTED
→ FRAGILE
→ CONDITIONAL
→ ROBUST
```

Never jump to `ROBUST` merely because no obvious flaw was found.

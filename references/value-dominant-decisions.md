# Value-Dominant Decisions

Some decisions are driven primarily by user-owned values or preferences: lifestyle, autonomy, identity, family priorities, ethical commitments, or acceptable trade-offs.

The audit must separate:

- **Factual premises** — claims that can be checked with evidence.
- **Values / preferences** — criteria owned by the user or legitimate decision authority.
- **Trade-offs** — explicit conflicts between values or constraints.

Evidence can test whether a factual premise is accurate, but evidence does not prove that one legitimate preference is morally or objectively superior to another.

For value-dominant decisions:
1. identify the value criteria explicitly;
2. check whether the factual premises supporting those criteria are sound;
3. surface conflicts between values;
4. avoid converting the model's preferences into decision criteria;
5. report when two options are materially equivalent under the user's stated values and constraints.
